## Featured projects

### PACS AI Assistant — Policy, SOP, ERP & Training Knowledge Assistant

[Open the repository](https://github.com/pradeep231790/pacs-ai-assistant)

A retrieval-augmented knowledge assistant for Primary Agricultural Credit Societies. Staff can search administrator-verified policies, circulars, guidelines, SOPs, ERP manuals, training documents, and updates, with cited source excerpts. Built with Python, Streamlit, SQLite, TF-IDF retrieval, and optional OpenAI generation; includes Docker deployment, tests, safety guidance, and architecture documentation. Pilot starter; not connected to a live ERP or automatic policy feed.

### Aura Salon & Studio — Booking and Billing

[Open the repository](https://github.com/pradeep231790/mini-salon-booking-billing)

A responsive salon workflow app with service discovery, live appointment availability, booking management, an admin diary, invoice generation, and a salon assistant. Built with Python, SQLite, JavaScript, HTML, and CSS.

### Sales Performance Analysis — MySQL

[Open the repository](https://github.com/pradeep231790/sales-performance-analysis)

An end-to-end SQL analysis workflow covering database setup, sample data, validation, employee/product/department analysis, and advanced rankings. Includes a data dictionary and business questions.

### Sales Performance BI Analysis — MySQL

[Open the repository](https://github.com/pradeep231790/Sales-Performance-Business-Intelligence-Analysis---MySQL)

### Cooperative Reporting Portfolio — Anonymized Samples

[Open the repository](https://github.com/pradeep231790/cooperative-reporting-sample-portfolio) · [View live dashboards](https://pradeep231790.github.io/cooperative-reporting-sample-portfolio/)
